Release checklist

Notes for the spring release, with nested steps and common questions.

Nested steps

  • Plan the release
    1. Freeze the feature set
      • Review open issues
      • Tag the milestone
    2. Write release notes
  • Build and sign the packages
  • Publish to the stores

Review order

  1. Design sign-off
  2. Security review
  3. Accessibility pass
  4. Localization check

Frequently asked questions

Who approves a release?
The release manager, after the three sign-offs above are recorded.
How long does a build take?
About twelve minutes on a clean cache, under three with it warm.
Can I skip the accessibility pass?
No. It is required for every public-facing change.
Where are the release notes kept?
In the docs repository, under the current version folder.
