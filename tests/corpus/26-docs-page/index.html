Configuration

Tell the scheduler where your queues live and how hard to try.

Tidewater reads its settings from tidewater.toml in the working directory. Every key can be overridden with an environment variable: queue.url becomes TIDEWATER_QUEUE_URL.

NoteSettings are read once at start-up. Send SIGHUP to reload them without dropping jobs.

A minimal file

This is enough to run one worker against a local queue:

[queue]
url = "redis://localhost:6379/0"

[worker]
concurrency = 4
max_attempts = 5

Options

KeyDefaultDescription
queue.urlnoneWhere jobs are stored. Required.
worker.concurrency1Jobs run at the same time by one worker.
worker.max_attempts3Tries before a job moves to the dead-letter queue.
log.level"info"One of debug, info, warn or error.
